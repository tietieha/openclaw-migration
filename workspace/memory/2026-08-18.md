## 浏览器控制修复

**问题：** `browser control is disabled`，排查过程：
1. Playwright Chromium 未下载 → 运行 `npx playwright install chromium` 下载（183MB）
2. `executablePath` 指向 Edge 干扰了自动发现
3. `plugins.allow: ["feishu"]` 白名单排除了 browser 插件 → 加入 `"browser"` 后恢复

**最终修复：** 在 `openclaw.json` 的 `plugins.allow` 数组中加入 `"browser"`，重启 gateway 后浏览器控制正常工作。

## GCloud Dolphin 上传流程梳理

**目标：** 为宋铁亮提炼 GCloud Dolphin 版本管理上传能力（APK / ZIP）

**入口：**
- 控制台：`console.gcloud.tencent.com`
- 版本管理 iframe：`idc.gcloud.tencent.com`（含短时效 ticket）

### 认证

- Cookie：`GCLOUD_ID` + `GCLOUD_SESSIONKEY` + `platformID`
- CSRF token `g_tk` = `getCSRFToken(sessionKey)`（加法累积算法）
- Ticket 短时效（~10-30 分钟），每次操作前从主页 iframe.src 取新 ticket

### 上传 API 流程（4步）

1. `POST /uploadfile/newTask` → 返回 `UploadTaskID`
   - 参数：`gameid`, `productid`, `versionstr`, `versionType`(0=app/1=res), `regionid`, `filename`, `filemd5`
2. `POST /init` → 初始化分片
3. `POST /chunk` × N → 分片上传（FormData: taskId/chunkId/chunkSize/totalChunks/file）
4. `POST /complete` → 完成，轮询 `/getUploadStatus` 等待 `MD5_VALIDATED`

### 关键参数（实测）

- `gameId`: 468150469
- `productId`: 1001108
- `regionId`: 2100（对应「内部开发-Android」渠道）

### 注意事项

- 大文件（1.5GB APK）无法通过 Playwright `setInputFiles` 传输（50MB 限制）→ 直接调 API 分片上传
- `versionType=1` 资源更新还需要补充实操确认
- 「预发布」提交 API 需下次补抓
- Session 过期处理：每次先取新 ticket + 最新 cookies
